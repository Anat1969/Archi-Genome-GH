# Archi‑Genome — הגנום הצבעוני של האדריכלות

אפליקציית ווב בעברית (RTL) ללימוד, הבנה ויישום של תורת הצבע — מגלגל הצבעים של ניוטון ועד חזית בניין בתלת־ממד, בשמש אמיתית של אשדוד, עם נתונים שאפשר להגיש.

## מה חדש בגרסה 2.0

- **סטודיו חזיתות תלת־ממדי** (`/studio`): מבנה מגורים בן 6 קומות עם מרפסות, קומת מסחר, רפפות, גג פעיל, עצים ודמויות לקנה מידה.
  - חומרים פיזיקליים (PBR) עם טקסטורות פרוצדורליות: טיח, אבן, בטון חשוף, מתכת, עץ.
  - מסלול שמש מחושב לקו רוחב 31.8° לפי חודש ושעה, צללים, שעת זהב, לילה עם חלונות ותאורת רחוב, והפעלת מחזור יום.
  - Ambient Occlusion, Bloom ו־ACES tone mapping; מצב חסכוני והורדת רזולוציה אוטומטית במכשירים חלשים.
  - שישה תפקידי צבע (60/20/10/5/3/2) ושש תבניות מוכנות (ים־תיכוני אשדודי, העיר הלבנה, אבן ירושלמית, ברוטליזם, נורדי, טרקוטה).
  - ניתוח "גנום": LRV, ספיגות סולארית, סינוור, רוויה מול הנחיות מרחביות, הבחנת כניסה לנגישות (הפרש LRV ≥ 30), טמפרטורה — וציון מסכם.
  - ייצוא: הדמיה PNG, מפרט CSV, משתני CSS, העתקת מפרט, ושמירת פלטות בדפדפן.
- **גלגל ← סטודיו**: הצבעים שנחשפים בגלגל מוחלים על המבנה בלחיצה, לפי היגיון אדריכלי (הבהיר לגוף, הרווי להדגשה, הכהה למסגרות).
- **דף בית חדש** עם סליל DNA תלת־ממדי בצבעי הפלטה, הנפשות גלילה ומעברי עמודים.

## עמודים

| כתובת | עמוד | תיאור |
|---|---|---|
| `/` | דף הבית | סליל גנום תלת־ממדי, ערך, איך זה עובד, צבע בעולם, יישום |
| `/studio` | סטודיו חזיתות 3D | מבנה תלת־ממדי, שמש, חומרים, ניתוח גנום וייצוא מפרט |

| `/how-colors-work` | ציר צבעים עובדים | שלושה תחומים (מוזיקה, טבע חי, פיזיקה) עם כרטיסי דוגמה ומשבצות תמונה ניתנות לעריכה |
