# Archi-Genome PRO

מעבדה לפענוח ה-DNA המרחבי של תמונות וליצירת השראה אדריכלית, מאת ענת שטיבלמן.

**Deciphering the past, Synthesizing the future.**

האפליקציה מנתחת תמונה לארבעה מדדים: נפח, פתח, אור וחומריות; מציגה הסבר בעברית ופרופיל מגזיני, ומרכזת ניתוחים בחוברת ״הקתדרלה״. בדף ניתוח אפשר לחדד פרומפט וליצור הדמיה של מבנה בהשראת התוצאות.

## חשוב לדעת

**הקתדרלה אינה ארכיון פרטי:** הקוד טוען את כל הניתוחים, ללא סינון לפי משתמש. המיגרציות מאפשרות קריאה והוספה ציבוריות ותמונות המקור מקבלות כתובות ציבוריות.

**לא כל התוצרים נשמרים:** תמונת המקור, הציונים, הנרטיב והתיאורים נשמרים; הפרומפטים, ההדמיות החדשות והפרשנויות נשמרים רק בזיכרון הדף ונעלמים בעזיבה או ברענון. ייצוא PDF/PNG, מחיקה דרך הממשק וניתוח טקסט עצמאי אינם ממומשים כרגע.

הניתוח וההדמיות הם כלי השראה, לא אישור הנדסי, תכנון לביצוע או תחליף לבדיקת אדריכל/ית.

## טכנולוגיה

React 18, TypeScript, Vite 5, Tailwind CSS 3, shadcn/ui, React Router, Recharts ו-Lovable Cloud. הניתוח והיצירה משתמשים ב-Lovable AI דרך פונקציות צד שרת; מפתחות פרטיים אינם מיועדים לדפדפן.

## על התיעוד והמאגר

התיעוד מבוסס על סקירת קוד האפליקציה ב-24 באוקטובר 2026. סקירת קוד אינה אישור שהגדרות השירות החי או כל זרימות העבודה נבדקו. הבחנה זו מפורטת במסמכי הבדיקות והפרטיות.

הוספת המסמכים למאגר GitHub אינה מחברת אותו לסנכרון Lovable, אינה מעתיקה את קוד האפליקציה ואינה מפרסמת גרסה חדשה. אם המאגר מכיל רק תיעוד, יש לצרף אליו בנפרד את קוד המקור כדי להריץ את פקודות ההתקנה.
