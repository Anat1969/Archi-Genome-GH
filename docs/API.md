# שירותי ניתוח ויצירת השראה

[חזרה לתוכן העניינים](../README.md)

הקריאות נעשות דרך לקוח Lovable Cloud באמצעות `functions.invoke`. אין לפרסם מפתח AI בדפדפן. הדוגמאות סינתטיות ואינן כוללות פרטי חיבור אמיתיים.

## `analyze-genome`

בקשת JSON:

```json
{ "imageUrl": "https://example.org/architecture.jpg" }
```

`imageUrl` צריך להיות נגיש לשירות AI. הדפדפן שולח כתובת של תמונה שהועלתה, לא קובץ base64. הפונקציה מבקשת פלט מובנה באמצעות `extract_genome`.

דוגמת תשובה מוצלחת:

```json
{
  "volume": 80,
  "volume_description": "המסה הבנויה מודגשת בנפחים רציפים.",
  "aperture": 35,
  "aperture_description": "פתחים ממוקדים יוצרים קשר מדוד עם החוץ.",
  "light": 75,
  "light_description": "האור מדגיש עומק והבדלים בין המישורים.",
  "materiality": 90,
  "materiality_description": "הטקסטורה החומרית ניכרת בחזית.",
  "narrative": "הנפח והאור יוצרים שפה מרחבית מאופקת."
}
```

המודל מתבקש להחזיר ארבעה ציונים שלמים 0–100 ותיאורים בעברית. אין אימות סכימה עצמאי לפלט לפני החזרתו; אילוצי הטבלה מגבילים את הציונים בזמן שמירה. הפונקציה אינה מעלה תמונות ואינה שומרת רשומות.

| מצב | HTTP |
| --- | --- |
| הצלחה | 200 |
| חסר `imageUrl` | 400 |
| יתרה נדרשת בשירות AI | 402 |
| עומס/הגבלת בקשות AI | 429 |
| כשל אחר בשירות AI | 502 |
| מפתח חסר, פלט לא תקין או חריגה | 500 |

שגיאות מוחזרות כאובייקט `{ "error": "..." }`.

## `inspire-genome`

בקשת יצירה לדוגמה:

```json
{
  "volume": 80,
  "aperture": 35,
  "light": 75,
  "materiality": 90,
  "narrative": "מסה מאופקת עם אור פיסולי",
  "descriptions": {
    "volume_description": "נפחים רציפים",
    "aperture_description": "פתחים ממוקדים",
    "light_description": "אור מכוון",
    "materiality_description": "טקסטורות עשירות"
  },
  "customPrompt": "Photorealistic minimalist modern architectural building, no text."
}
```

בהיעדר `customPrompt` שאינו ריק נבנית הנחיה מן המדדים, התיאורים והנרטיב. בהינתן פרומפט מותאם הוא מחליף את הנחיית התמונה. הפונקציה מפיקה תמונה ופרשנות במקביל.

תשובה: `{ "imageUrl": "<כתובת או data URL של התמונה>", "interpretation": "<פרשנות בעברית>" }`.

הפרשנות מבוססת על הניתוח המקורי; התמונה החדשה אינה נשלחת לניתוח חוזר. אם הפקת הפרשנות נכשלת אך התמונה הצליחה, התשובה עשויה עדיין להיות 200 עם פרשנות ריקה.

### חידוד נוסח

הוסיפי `"mode": "refine"` לבקשה עם אותם נתוני DNA ופרומפט אופציונלי. תשובה: `{ "refinedPrompt": "<נוסח באנגלית>" }`. לא נוצרת תמונה במצב זה. כשהפרומפט ריק, ההנחיה הבסיסית משמשת לחידוד.

יצירה וחידוד משמרים שגיאות 402/429; שגיאות ספק אחרות מוחזרות כ-502. מפתח חסר, היעדר תמונה או חריגה מוחזרים כ-500. אין שמירת תוצרים בפונקציה.

## גבולות המימוש

שתי הפונקציות מטפלות ב-`OPTIONS` ומחזירות CORS המתיר כל מקור. אין בקוד בדיקת שיטת HTTP מפורשת, אימות משתמש יזום, הגבלת כתובות תמונה או אימות מלא של סוגי הקלט. התנהגות שער הגישה תלויה גם בתצורה הפרוסה, שלא נבדקה כאן.

אין לחשוף את הפונקציות כפתרון מאובטח לפרסום ציבורי בלתי מוגבל ללא בדיקת הרשאות, קלט ועלויות. הודעת לקוח כללית על כשל פונקציה אינה אבחון: יש לבדוק גם את גוף התשובה ויומני השירות.
