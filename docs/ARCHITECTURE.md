## עקרונות

1. **הפרדת תוכן מקוד** — כל הטקסט שמוצג למשתמש נמצא בקבצי `data/`. כדי לשנות ניסוח, מעדכנים שם ולא בתוך הרכיבים.
2. **עברית בלבד בממשק** — הקוד כתוב באנגלית, וכל הטקסט המוצג בעברית ובכיוון RTL.
3. **ניווט אחד משותף** — `TopNav` מוצג בכל העמודים ומדגיש את העמוד הפעיל.
4. **עיצוב דרך משתנים** — צבעים מוגדרים כמשתנים ב־`index.css` ו־`tailwind.config.ts`, לא כערכים קשיחים ברכיבים.

## גלגל הצבעים — לוגיקת המסכה (סופית, לא לשנות)

- מסכה שחורה מכסה את כל הגלגל בשקיפות שנבחרה בסליידר (0–100).
- המספר שנבחר קובע כמה חשיפות מותרות.
- כל לחיצה הופכת לשקוף לחלוטין רק את התא שנלחץ; שאר המסכה לא משתנה.
- "איפוס חורים" ו"בחירה חדשה" מנקים את כל החשיפות ומחזירים את המסכה לשקיפות הסליידר.

## פסיכולוגיית הצבעים — הספקטרום

- טווח רציף מאינפרא־אדום, דרך הספקטרום הנראה, ועד אולטרה־סגול.
- תזוזת הידית מעדכנת בזמן אמת את התדר ואת צבע התצוגה.
- רק בהגעה לאחת מ־7 נקודות העצירה (אדום, כתום, צהוב, ירוק, כחול, אינדיגו, סגול) מוצג פאנל ההסבר המלא.

## סטודיו חזיתות — עקרונות

- יחידות הסצנה הן מטרים. החזית הראשית פונה לדרום (‎+z), מזרח הוא ‎+x.
- לכל תפקיד צבע יש חומר אחד משותף; הצבע עובר בהדרגה ליעד, הגימור מתחלף מיד.
- הטקסטורות נוצרות על canvas בזמן ריצה — אין תלות ברשת.
- `worldBox` מגדיר UV במטרים, כך שגודל אבן/טיח נשמר בכל משטח.
- הספריות התלת־ממדיות נטענות רק בכניסה לסטודיו או לדף הבית (code splitting).
