# מדריך שימוש

[חזרה לתוכן העניינים](../README.md)

## המסלול מתמונה לרעיון

1. פתחי את ״ניתוח״ והעלי תמונה דרך בחירת קובץ או גרירה לאזור ההעלאה.
2. לאחר הופעת התצוגה המקדימה לחצי על ״זקק DNA״.
3. המערכת מעלה את התמונה, מבקשת ניתוח ושומרת את התוצאה. בהצלחה נפתח דף ״פרופיל גנטי״.
4. בדף הפרופיל מוצגים התמונה, תאריך הניתוח, גרף DNA, הנרטיב והסבר לכל מדד.
5. פתחי את ״הקתדרלה״ לעיון בחוברת הניתוחים השמורים.

אין צורך להתחבר. מאחר שהארכיון ציבורי ומשותף, אין להעלות תמונות או מידע סודיים.

## ארבעת המדדים

| מדד | מה הוא מתאר | משמעות ציון גבוה |
| --- | --- | --- |
| נפח — Volume | מסה, משקל, רציפות ופירוק הצורה | ביטוי מסיבי ומונוליתי |
| פתח — Aperture | שקיפות והיחס בין פנים לחוץ | פתיחות ושקיפות |
| אור — Light | אור כחומר פיסולי היוצר עומק ואווירה | משחק אור מכוון ודרמטי |
| חומריות — Materiality | מגע, טקסטורה וביטוי החומרים | ביטוי חומרי עשיר |

הציונים בטווח 0–100 הם הערכה פרשנית של AI, לא מדידה פיזיקלית או דירוג איכות. ההסבר לכל מדד מתייחס לתמונה שנבחרה. בניתוחים ישנים ייתכן שלא נשמרו תיאורים.

## הקתדרלה

- כל רשומת ניתוח מוצגת כעמוד אחד; החדשות מופיעות תחילה.
- דפדוף מתבצע בחצים, בנקודות או בחצי המקלדת.
- הפריסה מתחלפת בין תמונה רחבה, תמונה משמאל, תמונה מימין ופורטרט מרכזי. החיתוך הוא תצוגתי ואינו משנה את קובץ המקור.
- קישור הפרופיל פותח את הניתוח המלא; החוברת אינה מציגה את כל תיאורי המדדים בכל פריסה.
- ניתוח חדש אמור להתווסף ללא רענון באמצעות עדכונים בזמן אמת, כאשר הגדרות השירות מאפשרות זאת.

החוברת היא תצוגה דיגיטלית; אין כיום הורדת חוברת מודפסת או PDF. התאמה מושלמת לכל גודל מסך לא אושרה במסגרת כתיבת התיעוד.

## יצירת מבנה בהשראת הניתוח

בדף הפרופיל אפשר להשאיר את תיבת הפרומפט ריקה לשימוש בהנחיית ברירת המחדל, או להקליד הנחיה משלך. ברירת המחדל מבקשת מבנה מינימליסטי, חדשני, מודרני ומציאותי, שמתאים לצילום מגזין אדריכלות מקצועי, ומשלבת את ה-DNA והנרטיב.

1. לחצי ״חדד פרומפט״ כדי לקבל נוסח מדויק יותר באנגלית לתיבת הטקסט.
2. ערכי את הנוסח לפי הצורך.
3. לחצי ״צור מבנה בהשראת ה-DNA״ והמתיני להדמיה.
4. מתחת להדמיה תופיע פרשנות אדריכלית בעברית אם הפקתה הצליחה.

פרומפט מותאם שאינו ריק מחליף את הנחיית התמונה המלאה; כדי לשמור על קשר מפורש ל-DNA יש לכלול אותו בנוסח. הפרשנות נבנית מפרופיל הניתוח, ולא מניתוח מחודש של התמונה שנוצרה.

**הפרומפט, ההדמיה והפרשנות אינם נשמרים בארכיון.** שמרי עותק באופן ידני לפני עזיבת הדף אם ברצונך לשמור אותם.
